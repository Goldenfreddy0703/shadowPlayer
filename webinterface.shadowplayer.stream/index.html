📡 Using RTSP with Screen Stream

Step 1: Install "Screen Stream" app on your Kodi/Android device

Step 2: In Screen Stream settings, enable HLS output (not just RTSP)

Step 3: Start the stream - it will show an HLS URL like:

http://192.168.1.x:8080/stream.m3u8

Step 4: Enter that HLS URL above and click Play!

Note: Browsers cannot play RTSP directly. Screen Stream's HLS output provides browser-compatible streaming.
