📱 How to use with Screen Stream app:

  1. Install Screen Stream app on your Kodi/Android device
  2. Open the app and start the RTSP server
  3. Note the RTSP URL shown (e.g., rtsp://192.168.1.100:5540/screen)
  4. Enter that URL above and click Start Stream
  5. The service will transcode RTSP → HLS and play in your browser!
